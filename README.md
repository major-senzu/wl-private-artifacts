# WL Artifacts

Wanderlust 成果物の公開ビルド置き場。

## 運用ルール

このリポジトリは Public のため、以下を厳守する。

1. 置いてよいのは**暗号化ビルド済みHTML**（パスワード保護つきビルド）のみ。平文の業務成果物・画像・スクリーンショットは置かない
2. コミットメッセージは定型文（例: `update`）のみ。ファイル名・フォルダ名・コミットメッセージに固有名詞（取引先名・人名・部署名・案件内容）を書かない
3. 新規の格納先フォルダはコードネームを使う（既存フォルダ名は公開URLの互換のため維持）
4. ソースファイルはローカルワークスペース側で管理し、ここにはビルド成果物のみを置く
